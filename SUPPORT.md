# Support

This project is community-maintained and support is provided on a best-effort basis.

- Read [README.md](README.md) and [USAGE.md](USAGE.md) first.
- Use the bug report form for reproducible defects.
- Use the feature request form for narrowly scoped enhancements.
- Include the plugin version, Node.js version, operating system, Grok CLI version, and sanitized
  error output when applicable.

Do not include tokens, credentials, private repository content, environment-file contents, or
Grok session data. Security vulnerabilities belong in the private process described in
[SECURITY.md](SECURITY.md), not in public issues.
